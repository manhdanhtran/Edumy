# 09 — DDD §8 coverage: rule -> enforcing object -> existing test (P09 item 1)

`docs/prompts/P09-tests.md` item 1 asks for a `ConstraintsIT`. It already exists in spirit as the per-module
`*SchemaIT` classes (one section per migration, same constraint-by-constraint order as `schema-checklist.md`), so P09-a
adds NO parallel class: this table maps every row 1-31 of EDU-DDD-001 §8 to the test that proves it, and the gaps found
were filled in the matching `*SchemaIT`.

Shorthand (all under `src/test/java/com/edumy/`, all `@MySqlJdbcTest` and rolled back unless noted):
**ISC** = `identity/IdentitySchemaIT`, **ASC** = `authoring/AuthoringSchemaIT`, **CSC** = `commerce/CommerceSchemaIT`,
**LSC** = `learning/LearningSchemaIT`, **TSC** = `schema/TriggerSchemaIT`, **FMI** = `schema/FlywayMigrationIT`,
**CVT** = `shared/error/ConstraintViolationTranslatorIT` (maps the same violations to API ErrorCodes through JDBC and
Hibernate). Violating-row tests assert the exact constraint name (`SchemaAssertions.assertViolates/assertCheckViolated`)
or the BR code of the trigger SIGNAL (`assertSignals`).
